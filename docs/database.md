# StudyTwin AI Database Schema Documentation

## Mongoose Models Overview

1. **User**: Credentials, academic level, branch, graduation year.
2. **Subject**: User owned subject records with target exam date.
3. **Topic**: Nested under Subject with difficulty level and prerequisite topic IDs.
4. **StudySession**: Log of time spent, session type (Learning, Revision, Practice, Quiz, Coding), and notes.
5. **Quiz**: Question bank with difficulty rating and concept tags.
6. **QuizAttempt**: Score, timing, correct/incorrect list per user.
7. **TopicMastery**: Dynamic state of student's proficiency, calculated confidence, and calculated forgetting risk per topic.
8. **Recommendation**: Contextual study action items generated by recommendation engine.
9. **StudyPlan**: Generated tasks and schedules.
